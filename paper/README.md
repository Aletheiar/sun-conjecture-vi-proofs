# 无需运行程序的统一数学审阅稿

优先阅读 [完整 PDF（15 页）](./sun_vi_standalone_proof_2026-10-26.pdf)。
可编辑源文件为 [LaTeX](./sun_vi_standalone_proof_2026-10-26.tex)。

这份统一稿把三式证明重新组织成一篇连续的数学文档，不要求读者运行 Python，
也不要求读者打开 JSON 证书、构造器或早期研究日志。

## 内容

- 第 1 节：三条原始命题、出处、记号，以及明确列出的古典定理输入。
- 第 2 节：母函数推导、四维状态及逐分量微分/移位规则，有限和的望远镜推导。
- 第 3–4 节：VI1、VI2 的全部显式证书、超几何拉回的四个系数、解析唯一性及最终常数表。
- 第 5 节：VI3 的全部证书、固定参数权导数系统、Legendre 方程的显式拉回。
- 第 6 节：可求和主控、合法换极限、三项端点展开以及实际周期组合的唯一性。
- 第 7 节：从原级数独立确定非零边界常数，再用七次 CM 数据完成求值。
- 附录 A：四组证书的四分量有限代数检查规则、按 n 收集的系数表和非平凡分量的完整验算。
- 附录 B：最终 K²、KE 和常数项的逐步消去，不另假设辅助的 Ramanujan R3 公式。

有限有理函数恒等式可以按照印出的公式通分核查；正文没有把脚本成功退出当作证明前提。
标准特殊函数定理与两条经典 Ramanujan 求值仍按学术惯例引用原文，所需公式和条件已经列明。

## 制作与校验

统一稿在制作过程中另作了 77 项精确代数转写检查，并已检查全部页面渲染。
PDF 为 15 页，21 个字体均已嵌入，无未解析引用、缺字或溢出公式。
这属于作者方制作与核对记录，不代表专业数学审稿通过。
文件哈希和制作校验摘要见 [document_validation.json](./document_validation.json)。

源文件可用 XeLaTeX 或 Tectonic 编译；当前字体设置使用 Windows 的
Times New Roman、SimSun、SimHei、KaiTi 等字体。其他平台重新编译时可替换相应字体，
直接阅读 PDF 不需要安装这些字体，也不需要 Python。

本稿供孙教授及其他数学读者独立审阅，首次性与奖金资格尚未认定。
