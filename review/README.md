# DeepSeek 独立 AI 复核材料

这里保留收到的报告和九个独立复算脚本，便于审查独立重建的范围。
脚本不读取作者的 JSON 证书；报告的数学内容保持收件时原样。
本目录的副本仅脱除本机解释器路径、替换旧本机复现命令，并转换 Markdown 数学分隔符。
下载的参考论文、OCR 文本及旧运行日志不随仓库分发。

**先读 [逐条回应](../gpt_review_response_2026-10-26.md)。**
报告中 P1 的“分母错误”判断不成立，另有 Y 的二阶项、周期解基首项和通用主控的转述错误。
原稿相应步骤和正确表达见回应；不能把此历史报告的每句话当作已确认结论。
若干脚本打印的 sup / tail bound 来自有限抽样，只是数值查错。

AI 复核不是专业数学家的审稿，也没有确认首次性或奖金资格。

## 复算

从仓库根目录运行：

```sh
python -m pip install -r review/requirements-review.txt
python -I review/run_checks.py
```

运行器依次执行九个脚本，日志输出到被 Git 忽略的 `review/reproduced/`。
任一脚本失败即非零退出；数值脚本的成功退出不提升为证明。
公开报告保留原工作区目录和历史日志名称作为收件记录，这些历史路径不是当前运行的依赖。
